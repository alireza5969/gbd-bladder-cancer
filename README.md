## Summary

This is a descriptive analysis of Global Burden of Disease (GBD) 2021 estimates of bladder cancer incidence, prevalence, mortality, years lived with disability (YLDs), years of life lost (YLLs) and disability-adjusted life years (DALYs) for the United States, the 50 states and the District of Columbia. It includes benchmarking against the European Union and the high-income and high-SDI aggregates, age and sex patterns, and 2021 male:female rate ratios. It does not test causes or policy effects.

All numbers in the manuscript's Abstract and Results are generated from the data by the code in this repository.

## Data

- **Source:** [Global Health Data Exchange (GHDx) GBD Results Tool](https://ghdx.healthdata.org/gbd-results-tool), GBD 2021. Institute for Health Metrics and Evaluation (IHME), University of Washington.
- **Contents:** bladder cancer; incidence, prevalence, deaths, YLDs, YLLs and DALYs; both sexes, males and females; all ages, five-year age groups and age-standardized rates; U.S., 50 states and DC, European Union, high-income and high-SDI aggregates.
- **Years:** 1990–2021 for all measures; deaths and YLLs also for 1980–2021.
- **Uncertainty:** point estimates with 95% uncertainty intervals (UIs). Posterior draws are not part of the public download and are not included.
- **Format:** R data files (`.rds`).

Please also follow IHME's [terms and conditions](https://ghdx.healthdata.org/about-ghdx/terms-and-conditions) and cite the GBD 2021 publications when reusing the data.

## Reproducing the analysis

**Requirements**

- [R](https://www.r-project.org/) (version listed in Supporting File 9 of the manuscript)
- [Quarto](https://quarto.org/docs/get-started/) (≥ 1.4 recommended)
- R packages: `tidyverse`, `scales`, `glue`, `geofacet`, `ggnewscale`, `future`, `furrr`, `gganimate`, `paletteer`, `flextable`, `patchwork`, `ggbump`, `ggtext`, `knitr`, `rmarkdown` (exact versions are listed in the manuscript's Supporting File 9)

**Steps**

```bash
git clone https://github.com/alireza5969/gbd-bladder-cancer.git
cd gbd-bladder-cancer
# optionally check out the release matching the paper
git checkout v1.0 # to be corrected later
quarto render index.qmd --to docx   # or --to html
```

**Notes**

- Figures are cached: a figure is regenerated only if its file in `output/figures/` does not exist. Delete a file to rebuild it.
- Animated pyramids (GIFs) are slow to produce and run in parallel with 6 workers (see the `figure-pyramid-animated` chunk).
- At render time the manuscript reads the current `git` commit and prints it in the text. If you render outside a git checkout, a placeholder is printed instead.
- Percent changes and male:female ratios use approximate UIs computed from published bounds on the log scale, assuming independence and log-symmetry (see the manuscript's Methods). Posterior draws are not used.
